Responsive Layout Test

This page tests the responsive layout system for the Service Provider Dashboard.

📱 Mobile Layout (≤767px)

On mobile devices, you should see:

  • Collapsible sidebar with hamburger menu
  • Stacked header with role tabs and workspace switcher
  • Touch-friendly buttons (44px minimum)
  • Full-width modals with bottom sheet style
  • Horizontal scrolling tables
  • Single column grid layouts

📱 Tablet Layout (768px-991px)

On tablet devices, you should see:

  • Narrower sidebar (200px)
  • Horizontal header layout
  • 2-column grid layouts
  • Medium-sized modals

🖥️ Desktop Layout (≥992px)

On desktop devices, you should see:

  • Full sidebar (240px)
  • Horizontal header layout
  • Multi-column grid layouts
  • Large modals
  • No mobile navigation toggle
